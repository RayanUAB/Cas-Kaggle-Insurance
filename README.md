# Cas Kaggle - Insurance

## Objectiu

L'objectiu d'aquest projecte és predir les despeses mèdiques (`charges`) d'una persona a partir de sis atributs: `age`, `sex`, `bmi`, `children`, `smoker` i `region`. Es tracta d'un problema de regressió.

## Dataset

Utilitzem el dataset [Medical Cost Personal Datasets](https://www.kaggle.com/datasets/mirichoi0218/insurance), disponible a Kaggle. Conté inicialment 1.338 registres i 7 columnes.

## Resultats principals

En l'anàlisi exploratòria hem vist que `smoker` és l'atribut amb més relació amb les despeses mèdiques. També hem observat que la relació entre `bmi` i `charges` és molt més forta entre les persones fumadores.

## Execució

1. Clonar o descarregar el repositori.
2. Col·locar `insurance.csv` a la mateixa carpeta que `APC_Cas_Kaggle_2026_v2.ipynb`.
3. Instal·lar les dependències amb `pip install -r requirements.txt`.
4. Obrir el notebook a VS Code o Jupyter i executar les cel·les en ordre.
